# Haoran (Matt) Wan | Personal Academic Website

Source code for my personal academic website: **[haoranwan.com](https://haoranwan.com)**

---

### About This Repository

This site is built with [Quarto](https://quarto.org/), an open-source scientific and technical publishing system. All content is written in Quarto-flavored markdown (`.qmd`) files.

The `main` branch holds the Quarto source; the rendered site is served from the `gh-pages` branch (published with `quarto publish gh-pages`) via GitHub Pages at the custom domain [haoranwan.com](https://haoranwan.com).

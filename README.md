---

### About This Repository

This site is built using [Quarto](https://quarto.org/), an open-source scientific and technical publishing system. All content is written in Quarto-flavored markdown (`.qmd`) files.

The site is automatically rendered and deployed via a [GitHub Actions](https://github.com/features/actions) workflow. The `main` branch holds the Quarto source code, and the live HTML/CSS/JS files are served from the `gh-pages` branch.
